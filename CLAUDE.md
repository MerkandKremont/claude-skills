# Itaca — Skill

Ogni skill è una cartella qui dentro con il suo `SKILL.md`. Claude Code le trova perché `~/.claude/skills` è un collegamento a questa cartella: per aggiungere una skill basta creare qui una nuova cartella con `SKILL.md`.

## Skill attive
- `/suno` — crea prompt per Suno (in inglese) da una reference, un mood o un'idea. `suno/learnings.md` è il registro condiviso di cosa funziona: aggiornalo quando qualcuno riporta un risultato testato su Suno.
- `/testo` — scrive testi in rima per Suno (max 5000 caratteri spazi inclusi) nello stile di un artista di reference. Chiede tipo di canzone e struttura prima di scrivere. `testo/learnings.md` è il registro condiviso; `testo/artisti/` contiene i profili degli artisti confermati dal team.

## Regole per le skill
- Quando crei una nuova skill, mettila in questa cartella e aggiungila alla lista qui sopra.
- Ogni skill che migliora con l'uso ha un suo `learnings.md`: ci vanno solo regole confermate da risultati veri.
